# CS306 - Programming Using Python

This repository contains the source code, practical exercises, and sample programs for **CS306: Programming Using Python**. It is organized sequentially by chapters to track progress through core programming concepts, modules, and mini-games.

## 📂 Repository Structure

```text
├── NOTES/             # Conceptual notes and documentation summaries
├── Chapter2.py        # Core basics: Variables, expressions, and data types
├── Chapter3.py        # Conditional execution: if, else, and elif blocks
├── Chapter4.py        # Functions: Definition, execution, and arguments
├── Chapter5.py        # Iteration: Loops, while, for, and control flow tools
├── Chapter6.py        # Strings: Traversal, slicing, and string methods
├── Chapter8.py        # Lists: Sequences, cloning, parsing, and list methods
├── Chapter9.py        # Dictionaries: Key-value stores, histograms, and lookups
├── Chapter10.py       # Tuples: Immutability, comparison, and tuple assignment
└── numbergame.py      # Interactive mini-game implementation
```

## 🎮 Projects Highlight
* **`numbergame.py`**: An interactive Python script practicing condition checks, loops, and logic building using a random number guessing game approach.

## 🚀 Getting Started

### Prerequisites
To run the scripts in this repository, ensure you have Python 3.x installed on your local machine. You can verify your installation by running:
```bash
python --version
```

### Installation & Execution
1. Clone the repository to your local system:
   ```bash
   git clone https://github.com
   ```
2. Navigate directly into the cloned folder:
   ```bash
   cd CS306-python
   ```
3. Execute any specific chapter script or game file directly (for example, to run the number game):
   ```bash
   python numbergame.py
   ```
